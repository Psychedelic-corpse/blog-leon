# Contexto del Proyecto: Blog de Leon Di Monte

Este repositorio contiene la web personal y el panel CMS de **Leon Di Monte** (`leondm.com`).

- **Frontend:** `apps/web` (Next.js 15 App Router, Tailwind CSS, `@portabletext/react`).
- **CMS:** `apps/studio` (Sanity Studio v3, `projectId: b0mw2pap`, `dataset: production`).
- **Live URL:** `https://leondm.com`
- **Studio URL:** `https://leondm.sanity.studio`
- **Documentación:** Ver `DOCUMENTACION.md` para comandos y detalles de configuración.
